Scheduling

What Scheduling Controls

Scheduling changes when NeutArr is allowed to process an app and how many API calls that app may make per hour. The scheduler checks once per minute and applies enabled schedules on the selected days and time.

Scheduling does not directly start a missing-media or quality-upgrade search. NeutArr's normal hunt cycle observes the enabled state and API cap set by the schedule.

Available Targets

Target Effect
All Apps (Global) Applies the action to every supported Arr app.
Sonarr, Radarr, Lidarr, or Readarr Applies the action to all configured instances of that app.
Whisparr V2 Applies the action to all configured Whisparr V2 instances.
Whisparr V3 Applies the action to all configured Whisparr V3 / Eros instances.

Available Actions

Action What It Does
Enable Allows the selected app or all apps to participate in hunt cycles.
Disable Pauses the selected app or all apps without removing its configuration.
API Limits Sets the hourly API cap to 5, 10, 20, 30, 50, or 100.

Create a Schedule

  1. Open Scheduling

    Select Scheduling from the NeutArr sidebar.

  2. Choose the day and time

    Select at least one weekday, then choose the hour and minute.

  3. Choose an action and target

    Select Enable, Disable, or an API limit, followed by the app it should affect.

  4. Add the schedule

    Select Add Schedule. NeutArr saves the schedule automatically and shows it in the current schedule list.

How Execution Works

  • The scheduler checks saved entries once per minute.
  • An entry runs only on its selected weekdays.
  • A four-minute execution window tolerates small startup or processing delays.
  • An entry is not run repeatedly during the same daily execution window.
  • Deleting a schedule removes it after confirmation.
  • Schedules are stored under /config/scheduler/schedule.json.

Common Patterns

Pause searches during busy hours

Add a Disable schedule at the start of the busy period and a matching Enable schedule when NeutArr may resume.

Reduce indexer activity temporarily

Set a lower API limit before the restricted period and restore the normal limit with a second schedule afterward.

Stagger multiple apps

Use different times for different apps to avoid a burst of requests when several hunt cycles become active together.

Troubleshooting

  • Confirm the schedule still appears in the current schedule list.
  • Check that the current weekday and NeutArr timezone match the schedule.
  • Allow for the scheduler's one-minute checks and four-minute execution window.
  • Confirm the selected app has a saved configuration.
  • Review NeutArr logs for rejected targets or failed settings updates.
